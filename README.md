# Blinkit-Power-bi-Dashboard
# 🛒 Blinkit Sales Analysis Dashboard – Power BI

## 📊 Project Overview

This project is an interactive **Blinkit Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard provides insights into sales performance, outlet characteristics, item types, fat content, outlet size, outlet location, and outlet establishment trends.

The goal of this project is to transform raw Blinkit sales data into an interactive business intelligence dashboard that helps users understand key sales and outlet performance metrics.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall sales performance.
- Understand sales distribution across different outlet types.
- Compare sales based on outlet size and location.
- Analyze item performance by item type.
- Compare sales between Low Fat and Regular products.
- Understand the relationship between outlet establishment year and sales.
- Provide interactive filtering using Power BI slicers.

## 📈 Dashboard Features

### 1. Outlet Establishment Analysis

The dashboard includes a trend analysis showing total sales based on the **Outlet Establishment Year**.

This helps identify how outlet establishment periods contribute to overall sales performance.

### 2. Fat Content Analysis

Sales are analyzed based on product fat content:

- Low Fat
- Regular

The dashboard uses a donut chart to visualize the contribution of each category to total sales.

### 3. Item Type Analysis

The dashboard provides a breakdown of sales across different item categories, including:

- Fruits & Vegetables
- Snack Foods
- Household
- Frozen Foods
- Dairy
- Canned
- Baking Goods
- Health & Hygiene
- Meat
- Soft Drinks
- Hard Drinks
- Breads
- Starchy Foods
- Others
- Breakfast
- Seafood

### 4. Outlet Size Analysis

Outlet performance is analyzed across:

- Tier 1
- Tier 2
- Tier 3

This helps identify which outlet sizes contribute most to total sales.

### 5. Outlet Type Analysis

The dashboard compares different outlet types using:

- Number of Items
- Total Sales
- Average Sales
- Average Rating
- Item Visibility

Outlet types include:

- Grocery Store
- Supermarket Type 1
- Supermarket Type 2
- Supermarket Type 3

### 6. Interactive Filters

Users can dynamically filter the dashboard using:

- **Outlet Location Type**
- **Outlet Size**
- **Item Type**

These slicers allow users to explore specific segments of the data.
